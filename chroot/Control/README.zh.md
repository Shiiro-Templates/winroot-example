# Control

`chroot` 的小型控制和参考区域。它记录树的使用方式，
但不期望能重新创建 Windows 或每个传统安装的程序。

- `Environment`：属于此树的环境变量和 PATH 设置。
- `Inventory`：人写或工具生成的已安装软件和受管资源记录；
  描述性记录与期望状态文件同样有效。
- `Profiles`：你有意保留的 shell、编辑器、终端和工具设置。
- `Scripts`：启动、设置、验证和维护脚本。
- `Templates`：可复用的配置和项目模板。
- `Exports`：从 Windows 或应用导出的快照，用于参考或恢复。

凭证放在 `../State/Secrets`，不要放在这里。
尽量使用文本格式，并通过 `%CHROOT_ROOT%` 而非盘符引用根目录。
一个记录可以简单描述安装了什么以及在哪里；自动化是可选的。
