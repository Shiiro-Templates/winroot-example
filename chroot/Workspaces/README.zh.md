# Workspaces

活跃的用户自有工作单元。每个子目录应可作为连贯的项目边界移动、归档或备份。

- `Projects`：不适合主要用源码控制仓库建模的项目，包括设计、写作、研究和混合交付物。
- `Repositories`：源码控制工作树，按稳定的项目 ID 或托管平台/所有者分组（在规模合理时）。
- `Labs`：值得保留的命名实验和原型。
- `Scratch`：明确短期无保留承诺的工作。

仅在工具要求时才把依赖和构建产物保留在仓库内部。否则使用 `../Cache/Packages`
和 `../Cache/Builds`。将已完成非活跃的工作移入 `../Archive/Projects`；
不要把 `Archive` 当作自动倾倒场。
