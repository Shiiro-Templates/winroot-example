# Software

位于 `chroot` 下的实际软件本体。它们不假定能通过清单重建：
传统的 Windows 安装器、包管理器、便携归档或手动 SDK 设置都可能拥有各自的子树。

- `Installed`：由传统安装器放置的程序体（目标路径可选）。
- `Portable`：有意作为便携方式管理的自包含应用。
- `Toolchains`：SDK、编译器、运行时、构建系统和开发工具。
- `PackageManagers`：完整的包管理器根目录，如 Scoop 或 Chocolatey。
- `Shared`：被多个应用使用的共享运行时和组件。
- `Shims`：稳定的启动器，对 PATH 可见。

使用安装器所期望的厂商或产品边界，并保留其内部布局。
不要强行把每个程序体套入一个发明的小写 ID，也不要在产品不支持时拆分相邻状态。
状态和缓存只有在路径确实可控时才应使用 `../State` 和 `../Cache`。
个人和项目文件永远不属于这里。
