# Cache

可丢弃、派生或可重新下载的内容。删除整个目录绝不能摧毁任何重要内容的唯一副本。

- `Downloads`：机器管理的下载缓存。
- `Packages`：包管理器和依赖缓存，按工具 ID 分组。
- `Builds`：在可行时保存在项目树之外的派生构建产物。//解释意义，干嘛
- `Apps`：每应用缓存 //重定向不现实
- `Logs`：有限保留的非审计诊断日志。//无法显式区分
- `Temp`：进程临时数据和临时文件。//错误，本来的意图是重定向windowstemp变量中属于用户的环境变量部分

如果一个条目不能被安全删除，它就不是缓存：把持久的软件状态放在 `../State`，
传入的用户下载放在 `../Inbox/Downloads`，长期创作内容放在 `../Home`。
