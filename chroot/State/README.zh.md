# State

路径位置可以合理控制的持久可变软件状态。这是为选定的应用和工具选择性提供的
归宿，而不是 Windows AppData 和 ProgramData 的完整镜像或替代品。

- `Apps`：每应用的配置和持久数据。
- `Tools`：SDK、包管理器、IDE 和命令行工具的状态。
- `Shell`：不在 `Control/Profiles` 中的交互式 shell 状态。
- `Secrets`：需要独立访问和备份策略的凭证和私钥。

当你控制路径时，使用稳定的应用边界，如 `Apps/obsidian`。
在边界内部，保留程序所期望的布局；`config`、`data` 或 Windows 兼容布局
是可选的，不是强制的。如果软件坚持使用真实的用户配置目录，
就让它留在那里，而不是构建一个脆弱的语义假象。
任何可安全重新生成的内容属于 `../Cache`，
而用户创作的文档和知识属于 `../Home`。
