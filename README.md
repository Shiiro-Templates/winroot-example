## 今天想做点啥？
```tree
├── Control/        # 环境变量、脚本、配置文件源件、命令日志、需求记录
├── Software/       # 软件本体、运行配置、功能载荷、缓存、包管理器、源码构建消费品
├── UserSpace/      # 用户操作空间：自主知识内容、私人文件等 
├── Projects/       # 研发工作区：你开发与维护的源码项目
└── Archive/        # 暂离活跃视野的归档材料与状态快照
```
