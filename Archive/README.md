# Archive

暂时撤出日常视野的材料。
用于**管理注意力**，顺便安放“万一用得上”的囤积欲。“最近不折腾了”就挪进来

## 结构：基本镜像原始位置

```tree
Archive/
├───Projects/      # 暂离或结项的代码仓库（对应 ../Projects/）
├───Knowledge/     # 封存的旧专题与笔记库（对应 ../UserSpace/Knowledge/）
├───Software/      # 有意留存的旧安装包、便携软件副本
└───Snapshot/      # 从各类服务或应用导出的历史状态快照
```

## 边界说明

- 不放未分类的临时文件*：想清楚归宿再归位，别把 `Archive` 当成逃避分类的杂物间。没分类的东西放在对应的inbox位置，如刚下载还没想好去向的东西先留在 `../UserSpace/Downloads/`

## 设计思路 

- **整存整取**：从 `../Projects/` 或 `../UserSpace/Knowledge/` 移入时保持原有目录粒度，方便日后直接移回原位，无需重新整理。
- **静音降噪**：日常在工作区全局搜索或让 Agent 巡检活跃任务时，默认跳过此目录，减少视线干扰。
